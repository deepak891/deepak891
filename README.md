## 🚀 Featured Project

### 📈 Algo Trader — Personal Trading Terminal
> A fully-featured personal trading terminal for NSE/NFO markets, built on the Angel One (SmartAPI) broker. Designed to feel like Zerodha Kite — but with algo strategy superpowers.

- 📡 **Live Watchlist** — 60,000+ instruments, real-time prices via WebSocket
- 📊 **Candlestick Charts** — OHLCV with local caching (lightweight-charts engine)
- 📋 **Order Management** — place, modify & cancel NSE/NFO orders with a built-in risk gate
- 🤖 **Algo Strategies** — Short Strangle, Iron Condor; 6-step wizard, visual risk rules + embedded Python editor
- 🛡 **Risk Engine** — kill switch, daily loss limits, max order value, market hours gate

**Tech:** `FastAPI` `React 18` `TypeScript` `SQLite WAL` `Redis` `Docker Compose` `Nginx` `Angel One SmartAPI`

**Status:** ✅ Phase 1–3 complete · 🚧 Phase 4 in progress (Algo execution, live tick relay)
